# ALGORYX Internship — Week 2

## Professional landing page

This implementation follows the Week 2 internship requirements while keeping the visual language restrained and product-studio oriented rather than using generic AI-style gradients, excessive cards or decorative copy.

### Required functionality covered

- Responsive navigation bar
- Animated hero section
- Smooth scrolling
- Scroll reveal animations
- Parallax movement in hero artwork
- Animated counters
- Process timeline
- Interactive project/service cards
- Testimonials
- Services section
- Pricing section
- Contact form with validation
- Dark / light theme
- Scroll progress indicator
- Responsive mobile layout

### Technical implementation

- React + Vite
- Functional components
- React hooks
- Framer Motion
- Lucide React
- Reusable data arrays
- Responsive CSS
- Reduced-motion accessibility support

### Run

```bash
npm install
npm run dev
```

### Production check

```bash
npm run build
```

Do not include `node_modules` in GitHub.
