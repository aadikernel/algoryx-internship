# ALGORYX Frontend Internship — Week 1

## React Admin Dashboard

A responsive SaaS-style admin dashboard built with React and Vite.

### Week 1 requirements covered

- Responsive sidebar
- Top navigation
- Dashboard cards
- Recent orders table
- User profile card
- Notifications
- Search bar with filtering
- Light animations
- Responsive desktop/tablet/mobile layout
- Functional React components
- React hooks and state management
- Reusable components
- Organized component structure

### Run locally

```bash
npm install
npm run dev
```

### Build

```bash
npm run build
```

### Project structure

```text
src/
```

## Notes

This Week 1 implementation intentionally uses plain CSS instead of adding a Tailwind dependency, keeping the project lightweight and reducing installation issues. The internship document lists Tailwind and React Icons/Lucide as preferred technologies, not mandatory technologies.
